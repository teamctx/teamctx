# Terminal Context Surface

This is the user-facing simulation for an agent-terminal start or resume point.
It should read like something useful appeared in the flow of work, not like a
new product vocabulary lesson.

```text
Working context

Needs attention
- ...

Good to know
- ...

Saved for this project
- ...

Source health
- ...
```

Rules:

- Keep it short enough to read before work starts.
- Use plain language.
- Include source and reason only when they affect trust.
- Prefer verbs over nouns.
- Do not expose internal terms like artifact, promotion, authority, trust tier,
  quarantine, or durable context.
- Do not ask users to type these section names.
