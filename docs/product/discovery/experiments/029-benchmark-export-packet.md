# E-029: Benchmark Export Packet

## Purpose

Export the six primary executable benchmark fixtures into ready-to-run prompt
files and a run sheet.

## Product Question

Can TeamCtx produce a benchmark packet directly from the same fixture/rendering
path used by the terminal prototype?

## Hypothesis

A generated packet is safer than a hand-maintained prompt pack because it reduces
prompt drift from the actual product surface.

## Output

A generated benchmark packet containing:

- six baseline prompts,
- six context prompts,
- one run sheet.
