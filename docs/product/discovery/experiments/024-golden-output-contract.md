# E-024: Golden Output Contract

## Purpose

Create exact expected outputs for the fixture-backed prototype.

## Product Question

Can the first prototype have crisp, testable output before implementation?

## Hypothesis

Golden files will protect the product from drifting into verbose, internal, or
memory-like language during the first implementation.

## Output

Golden files for:

- default working context,
- `Show why`,
- context after using an advisory note in session,
- benchmark context prompt.
