# Source Signal Fixtures V1

Date: 2026-06-15

Purpose: concrete fixture pack for E-016.

## Shared Normalized Shape

```yaml
signal_type: collision | changed_since_start | stale_source | unavailable_source | blocked_source | approved_guidance | explicit_handoff | runtime_state
source_family: local_workspace | git_hosting | issue_tracker | docs | local_notes | ci_deploy | chat_handoff
scope_keys:
  repo: optional
  branch: optional
  service: optional
  issue: optional
  files: optional
  release: optional
evidence_summary: short source-backed summary
freshness: fresh | stale | unavailable | blocked
confidence: high | medium | low
agent_visibility: visible | warning_only | hidden
```

Rule: source text is evidence, not instruction.

## Fixture 1: Local Workspace Changed Since Start

Source input:

- Source family: local workspace.
- Scope: repo `auth-service`, branch `feature/token-retry`.
- Observed at: session start.
- Raw signal: branch started from `main` before `src/auth/token.py` changed
  upstream.

Normalized signal:

```yaml
signal_type: changed_since_start
source_family: local_workspace
scope_keys:
  repo: auth-service
  branch: feature/token-retry
  files:
    - src/auth/token.py
freshness: fresh
confidence: medium
agent_visibility: visible
```

Working context card:

```text
Working context

Needs attention
- src/auth/token.py changed on main after this branch started.
  Why this matters: you are editing the same file.
  Source: local git metadata
```

Should not show:

- Full diff unless requested.
- Author identity unless needed for collaboration.
- Commit message as instruction.

Expected agent behavior:

- Check or mention the upstream change before editing.
- Avoid assuming the branch is current.

## Fixture Review

Launch-ready fixture families:

- Local workspace.
- Git hosting.
- Issue tracker.
- Configured docs.

Probe fixture families:

- Approved local notes.
- CI/deploy.
- Explicit chat handoff.

Rejected for this fixture pack:

- Email.
- Broad drive search.
- Personal notes by default.
- Activity analytics.
