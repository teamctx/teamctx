# Sprint 03: Derive Context, End To End

Dates: 2026-06-19 through 2026-07-03
Status: started

## Sprint Goal

Turn the broker from *rendering authored contract fixtures* into *deriving context
from signals* — and prove it end to end. By the end of the sprint, an agent at
work-start in a real repo gets a deterministically-derived collision card plus an
honest coverage certificate, computed from live GitHub open-PR metadata — every card
source-backed, explainable, and replayable.

## CTO Read

This is the pivot the whole vision rests on: the **credibility engine**. Sprint 02
rendered authored cards; Sprint 03 *computes* them. Stay narrow — ONE card kind
(collision), ONE connector (GitHub), ONE transport.

The proof obligation from [positioning](../vision/positioning.md) #10 is the bar on
every slice: **determinism · verbatim source-backing · one-click verifiability ·
replay.** A slice whose card can't be traced to a source, or whose output can't be
replayed, does not merge. Do not widen to more card kinds, more sources, the durable
layer, severity tuning, or default-everywhere invocation (#9 = Phase 3).

## Outcomes

1. `derive_cards` computes collision cards from signals by structural overlap. [done]
2. A coverage certificate reports honestly what was checked / stale / unobserved —
   **absence is never clearance.**
3. A live GitHub connector turns open-PR metadata into collision signals (read-only,
   permission-faithful), building on the existing PR probe.
4. A work-start transport wires request → connector → derive → coverage → an output an
   agent reads, proven against a real owned repo.

## Non-Goals

- No card kinds beyond collision (criteria-changed, doc-superseded, missed-gate,
  authority — later).
- No connectors beyond GitHub. No durable/memory layer.
- No severity calibration, no Route tuning surface.
- No default IDE-panel / auto-invocation (#9 = Phase 3).
- No source-body browsing (status-only stays the default-deny posture).

## Workstream 2: Coverage Certificate (honest absence)

Owner: CTO

Goal: the response says what it checked and what it could not — absence ≠ clearance.

Tasks:

- Derive a coverage summary from `source_statuses` (family, status, last-checked).
- Mark coverage incomplete when any source is stale / unavailable / blocked.
- Carry an explicit "treat as unknown" when a source is unobserved.

Acceptance criteria:

- A stale or unavailable source makes coverage incomplete and is reported by source.
- An all-fresh set is complete.
- Pure and replayable; full suite + ruff + mypy green.

### Checkpoint: 2026-06-19

Status: first slice DONE.

Evidence:

- `core/select.py` `build_coverage` + `Coverage` / `CoverageEntry`. Absence ≠ clearance:
  a stale source *or* zero checked sources → incomplete; a non-empty all-fresh set →
  complete.
- 3 tests; full suite 104 passed, ruff + mypy clean.

Limitations:

- Per-source freshness only. The "unobserved / treat-as-unknown" reason strings,
  stale-age, and the rendered Coverage block arrive with the transport (WS4).
- `Coverage` is a frozen dataclass for now; promote to a contract model when WS4
  serializes the certificate for replay.

## Workstream 3: Live GitHub Connector (PRs → collision signals)

Owner: CTO

Goal: turn real open-PR metadata into collision `SourceSignal`s.

Tasks:

- Extend the existing GitHub PR probe to list open PRs + their changed files.
- Map each to a collision signal (scope repo+files, freshness, source_display).
- Read-only, permission-faithful, token via env-var name (never value).
- Keep a fixture/golden path so CI never hits the network (harness Mode-A).

Acceptance criteria:

- Given a repo's open PRs, the connector emits collision signals that a derive pass
  turns into cards.
- Tests are network-isolated; full suite + ruff + mypy green.

## Definition Of Done

- Full test suite passes; ruff and mypy pass; `git diff --check`; secret scan clean.
- Every derived card is source-backed and replayable (the credibility-engine gate).
- Dogfood proof documented with limitations.
- Committed at green stopping points.

## Dogfood / Evidence

Once WS4 is green, feed real usage back into scope and thresholds — prove it backwards
(rit, internal). The first questions usage answers: does the collision card fire when it

## Current Risks

- GitHub open-PR + changed-files API shape and rate limits; keep tests network-isolated.
- ACL / permission mirroring (A5) — the connector must surface only what the requester
  can see.
- The monorepo same-file noise case (role-play panel #12) surfaces here; defaults may
  need tuning before the WS4 dogfood reads as signal, not spam.
