# Phase 5 Harness Implementation Plan (emulation/ skeleton + GitHub-row drivers)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Phase 5 driver harness exists in-repo and the GitHub-only scenario rows (1, 3, 5, 7, 9, 10, 11, 12 of the program spec) are implemented as runnable drivers, so evidence collection starts the moment execution is authorized; Phase-4-dependent rows (2, 4, 6, 8) get stubs that report "not yet wired" honestly.

**Architecture:** BINDING design: `docs/superpowers/specs/2026-07-03-phase5-emulation-program.md` REVISION 2 (the pins are law: actor model keyed on branch/order not identity; fresh `session_id` per hook invocation; drivers live in teamctx; the redaction map; per-span byte-exact vs templated expectations; row 12 via the `TEAMCTX_GITHUB_API_ROOT` seam; criteria row operation ORDER). New top-level `emulation/` (NOT in the package; excluded from coverage; ruff/mypy still apply), stdlib-only plus the teamctx package itself.

**Safety rail (binding):** the BUILDER never makes live network calls and never touches real GitHub/GitLab/Atlassian. Drivers take the lab targets from env (`P5_GITHUB_LAB_REPO`, `P5_WORKDIR`, tokens from the standard envs) and hard-fail with a plain message when unset. Development/validation of the harness itself uses: local tmp git repos, the `TEAMCTX_GITHUB_API_ROOT` seam pointed at the bundled mock server, and synthetic PreToolUse events. LIVE execution is the CTO's step after review, never the builder's.

**Branch:** worktree `git worktree add ../teamctx-p5 -b feat/p5-harness main`. Another builder is active in ../teamctx-s9a; never touch it or main. Gate per commit: `python -m pytest -q -p no:cacheprovider && ruff check src tests emulation && python -m mypy src` and the em-dash grep over `src tests emulation` empty.

### Structure (pinned)
```
emulation/
  README.md            # how to run; the safety rail; env contract
  runner.py            # CLI: run one row or all; writes evidence dirs
  evidence.py          # expected-vs-actual: per-span byte-exact/templated diffing; PASS/FAIL
  redact.py            # the spec's redaction map, applied before anything is written
  mockgh.py            # local HTTP server speaking just enough GitHub REST+GraphQL for the
                       # fabricated-payload rows (row 12's 301-PR payload; gate shapes)
  actors.py            # clone/branch/commit helpers (tmp or lab checkouts); fresh session ids;
                       # synthetic PreToolUse event builder (exactly the fields hook.py reads)
  rows/
    row01_collision_github.py ... row12_unbounded.py   # one module per row; rows 2/4/6/8 are
                       # honest stubs: they exit with "requires the S9b/S10/S11 connectors"
```
